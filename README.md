# Merifa

Merifa gère le stockage de votre ordinateur et désinstalle proprement vos applications et jeux, restes compris.

🛍️ **Disponible sur le Microsoft Store** — 1 mois d'essai gratuit, puis 2 € par mois, sans engagement.
